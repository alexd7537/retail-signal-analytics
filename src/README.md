# Código del proyecto

Empieza por [analyze.py](analyze.py): prepara los datos, calcula indicadores y crea la base SQLite. Los demás scripts construyen o verifican los entregables. Los archivos `.mjs` corresponden a Excel e identidad visual.

Para ejecutar el flujo con todas sus dependencias y carpetas, descarga y extrae el [proyecto completo](../Retail_Signal_Proyecto_Completo.zip). Esta carpeta permite revisar el código en el navegador.
